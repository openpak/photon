# Provenance: photon

This server began as a fork of **BlackIce.Server** by Black Ice Server (Nate), an independent
Photon PUN server for the Unity game Black Ice, released under the GNU General Public License
v3.0. Its history is kept in this repository with the original authorship. OpenPak's work since
the port (2026-09-07) is AGPL-3.0-only; GPLv3 section 13 allows the combination, and the
upstream-authored code remains available under the GPL-3.0.

The transport and LoadBalancing protocol and the Fusion Shared-mode host are clean-room: the
repository holds only original code and protocol documentation, none of the game's binaries,
assets or decompiled source. The PC-side client mods and asset tooling live in an earlier copy of
the Photon server.
